## 三人分头

### 乙（后端 / API）

按顺序做，每做完一个用 `/docs` 里的 "Try it out" 点一遍：

1. **建 SQLite 表**（`backend/app/db/`）
   ```sql
   CREATE TABLE datasets (
       id INTEGER PRIMARY KEY AUTOINCREMENT,
       filename TEXT NOT NULL,
       stored_path TEXT NOT NULL,
       rows INTEGER NOT NULL,
       columns INTEGER NOT NULL,
       uploaded_at TEXT NOT NULL
   );

   CREATE TABLE trainings (
       id INTEGER PRIMARY KEY AUTOINCREMENT,
       dataset_id INTEGER NOT NULL,
       model_type TEXT NOT NULL,
       version TEXT NOT NULL,
       trained_at TEXT NOT NULL,
       train_rows INTEGER,
       valid_rows INTEGER,
       accuracy REAL,
       macro_f1 REAL,
       model_path TEXT,
       FOREIGN KEY (dataset_id) REFERENCES datasets(id)
   );
   ```

2. **实现 `POST /datasets`**：接收文件 → 存到 `uploads/` → 落库 → 返回 id
3. **实现 `GET /datasets/{id}/profile`**：调 `io_csv.profile_csv()`
4. **实现 `POST /trainings`**：调 `train.train_model()` → 模型存 `models/` → 落库
5. **实现 `GET /models`**：查表返回

> 注意：`io_csv.py` 和 `train.py` 现在是空壳（`NotImplementedError`）。你要么自己先实现 `io_csv.py`（这是你的地盘），要么和丙约定一个时间点，他把 `train.py` 填好。

### 丙（模型 / 验证）

1. **填 `backend/app/services/train.py` 的 `train_model()`**
   - 装 sklearn：`python -m pip install scikit-learn -i https://pypi.tuna.tsinghua.edu.cn/simple`
   - 实现 `RandomForestClassifier(n_estimators=100, random_state=random_seed)`
   - 用 `train_test_split(..., random_state=random_seed, stratify=y)`
   - 算 accuracy / macro_f1 / 混淆矩阵 / 每类 precision-recall-f1
   - 返回 `TrainingResult`

2. **填 `backend/app/services/predict.py` 的 `predict_batch()`**
   - 用 `model.predict_proba()` 拿概率
   - 组装 `PredictionRow`

3. **写一个本地对比脚本** `backend/tests/check_train.py`
   - 用 `kpi_train_small.csv` 跑 `train_model()`
   - 断言 accuracy 在 0.85–0.95 之间（参考值 0.89）
   - 断言混淆矩阵是 6×6，且元素和 = 100
   - 断言跑两次结果完全一样（可复现）

## 周五演示 A 的验收台词

演示时按这个顺序走，一句话一步：

1. "这是数据集上传页，我传一份 500 行的训练数据。"
2. "后端返回 500 行 9 列，画像显示 6 个故障类别分布正常。"
3. "点训练，选随机森林。"
4. "训练完成，Accuracy 0.89，Macro-F1 0.88。这是混淆矩阵。"
5. "注意 T5 那一行只有 8 个预测正确，这是模型最弱的类别——我们没打算优化它。"
6. "现在传一份异常数据，缺了一列。" → 界面显示红色错误提示。
7. "这就是我们的格式校验。"

> 第 5 句很重要：**主动说出模型哪里不好**，比假装完美更能拿分。
