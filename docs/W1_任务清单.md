# W1 任务清单（本周）

> 目标：**三个人都能在自己电脑上启动后端、访问 /health、看懂接口契约。**
> 本周不写业务代码。

---

## 完成标准（周五检查）

- [ ] 每个人 `git clone` 下仓库
- [ ] 每个人 `python -m uvicorn main:app --reload` 能启动
- [ ] 每个人浏览器打开 `http://127.0.0.1:8000/health` 能看到 `{"status":"ok"}`
- [ ] 每个人能说出 5 个接口各自干什么
- [ ] `docs/api.md` 三人过一遍，有异议当场提

**任何一条没做到，W2 不要开始。**

---

## 三人分工

### 甲（前端）

**做**：
1. clone 仓库，跑通后端（不写代码，先确认自己能启动）
2. 打开 `http://127.0.0.1:8000/docs`，把 5 个接口挨个点一遍
3. **画一张草图**：纸上或 Figma 都行，画出 4 个页面长什么样
   - 数据集列表页
   - 训练页（选数据集 → 选模型 → 点训练）
   - 评估结果页（混淆矩阵 + 指标表）
   - 批量预测页（上传 → 表格 → 导出按钮）
4. 把草图拍下来发群里，让乙确认"这些数据接口都能给到"

**交付**：4 张页面草图 + 一句"每个页面需要哪些接口"

**不做**：不写任何前端代码（W3 才开始）、不改接口字段名

---

### 乙（后端 / API）

**做**：
1. 建 GitHub 仓库，把当前骨架推上去，三人都加为 collaborator
2. 写 `docs/api.md` 的最终版（我已给初稿，他负责确认和补充）
3. 建 SQLite 表结构：`datasets`、`trainings`、`models`（字段自己设计，但要在 api.md 里对齐）
4. 把 `GET /health` 保持可用（已实现，别改坏）
5. 写 README 的启动步骤（已有初稿，验证一遍是否准确）

**交付**：GitHub 仓库链接（三人可访问）+ 表结构设计 + api.md 定稿

**不做**：不动 `FEATURE_NAMES` 顺序、不调模型参数

---

### 丙（模型 / 验证）

**做**：
1. clone 仓库，跑通后端
2. 装 `scikit-learn`：`python -m pip install scikit-learn -i https://pypi.tuna.tsinghua.edu.cn/simple`
3. 把 `data/samples/baseline_knn.py` 的逻辑改写成**可调用函数**，放在 `backend/app/services/train.py`：
   ```python
   def train_model(df, model_type="random_forest", test_size=0.2, seed=42) -> dict:
       """返回 {"accuracy":..., "macro_f1":..., "confusion_matrix":..., ...}"""
   ```
4. 用 `kpi_train_small.csv` 本地跑通，确认能产出混淆矩阵
5. 把 `edge_cases/` 里 5 个异常文件各跑一遍，记录**每个文件应该报什么错**

**交付**：`train.py` 函数 + 一份"异常输入对照表"（文件 → 期望错误码）

**不做**：不改前端、不绕过 API 直接改数据库
